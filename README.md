# tensor-circuit-torch

**Differentiable Tensor networks for quantum simulation implemented in PyTorch** 

The most up-to-date source code for differentiable MPDO simulation of gated quantum circuits can be found in the folder `MPDO_circuit/`. 

The focus is strongly on the truncated bosonic representation of noisy photonic modes in coupled nonlinear waveguide circuits, but extensions to general noisy qubit circuits should be straightforward -- or contact me personally, see listed manuscripts.

This repository contains the source code accompanying the paper:
- **Optimizing Quantum Photonic Integrated Circuits using
Differentiable Tensor Networks**  
    - M. Van Regemortel *et al.* (2025) — [arXiv:2509.11861](https://arxiv.org/abs/2509.11861)
    - See folder `circuit_optimization/`
- **Modeling the Quantum Photon Statistics in Hybrid Light-Matter Integrated Circuits**  
    - M. Van Regemortel *et al.* (2025) — [arXiv:2605.23286](https://arxiv.org/abs/2605.23286)
    - See folder `MPDO_circuit/`
